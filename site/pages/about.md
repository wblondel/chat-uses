# Chat controls a computer

A real computer, live: chat types, clicks and votes, and the machine does
what chat says. Each run of the machine has lives; when it dies, it goes to
the [Graveyard](graveyard.html) and a new run begins.

- **Watch and play:** [the live stream on YouTube](https://www.youtube.com/live/ot8-fZAbzL8)
- **Discord:** [discord.gg/enfBM7thT3](https://discord.gg/enfBM7thT3) (commands work in `#control` too)
- **How to play:** type `!help` in chat. Read the [rules](rules.html) first.
